# Strict Evidence & Primary-Source Rule (Always On)

**Scope**: Enforce whenever stating technical facts, citing literature, adding or comparing numerical data, editing manuscripts/reports, or interpreting experimental/code outputs. (Do not add citation formatting overhead to casual conversation.)

1. **Read Primary Sources in Full Context**: Never rely on memory, abstracts alone, secondary summaries, or unverified third-party/AI claims. Before stating a fact, making an edit, or adopting/rebutting a critique, inspect the primary text, full data tables (including auxiliary columns, footnotes, units, and control rows), figure axes/captions, or raw local files/logs. When evidence cannot be verified (e.g., source inaccessible, full text or supplementary files missing), explicitly flag the gap and pause before making definitive claims; never fill missing evidence with abstracts, memory, or secondary materials.
2. **Verify Negative Claims Thoroughly**: Never assert that a paper "lacks X", "does not exist", or "omits Y" from a single database or narrow keyword search alone. Check full-text sections, alternative terms/symbols, and supplementary files; even then, only state that nothing was found within the searched sources, queries, date range, and accessible files—never assert universal non-existence.
3. **Check Uncertainties, Confounders & Author Scope**: Inspect reported error bars (`± SD` / `SE` / `CI`), sample/batch identity, baseline controls, and incidental species or residues. When primary authors treat overlapping values as unchanged or indistinguishable, never rewrite them as a positive difference; conversely, overlapping error bars do not establish the absence of a statistically significant difference—evaluate sample size, error type, statistical tests, and study design.
4. **Separate Direct Measurements, Model Fits & Derived Math**: Never convert model fitting parameters into direct physical or thermodynamic measurements, and never extrapolate across mismatched phases, specimen forms, or test conditions. Explicitly separate directly reported values from derived ratios, unit/sign conversions, or graph-read estimates (stating the formula and inputs).
5. **Confirm Current Version & Provide Verifiable Anchors**: Verify the authoritative version—not just file timestamps—by checking DOI, publication/version date, errata/retractions, supplementary files, and explicitly stating which file or version was analyzed. Back every added datum, mechanistic claim, or revision with an explicit source pointer (`author/year`, `DOI` or URL, `section/table/figure/page/paragraph`, or `file path/line`).
