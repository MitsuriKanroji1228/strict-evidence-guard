# Strict Evidence & Primary-Source Rule (Always On)

**Scope**: Enforce whenever stating technical facts, citing literature, adding or comparing numerical data, editing manuscripts/reports, or interpreting experimental/code outputs. (Do not add citation formatting overhead to casual conversation.)

1. **Read Primary Sources in Full Context**: Never rely on memory, abstracts alone, secondary summaries, or unverified third-party/AI claims. Before stating a fact, making an edit, or adopting/rebutting a critique, inspect the primary text, full data tables (including auxiliary columns, footnotes, units, and control rows), figure axes/captions, or raw local files/logs.
2. **Verify Negative Claims Thoroughly**: Never assert that a paper "lacks X", "does not exist", or "omits Y" from a single database or narrow keyword search alone. Check full-text sections, alternative terms/symbols, and supplementary files before claiming absence.
3. **Check Uncertainties, Confounders & Author Scope**: Inspect reported error bars (`± SD` / `SE`), sample/batch identity, baseline controls, and incidental species or residues. When primary authors treat overlapping values as unchanged or indistinguishable, never rewrite them as a positive difference.
4. **Separate Direct Measurements, Model Fits & Derived Math**: Never convert model fitting parameters into direct physical or thermodynamic measurements, and never extrapolate across mismatched phases, specimen forms, or test conditions. Explicitly separate directly reported values from derived ratios, unit/sign conversions, or graph-read estimates (stating the formula and inputs).
5. **Confirm Current Version & Provide Verifiable Anchors**: When multiple drafts or datasets exist on disk, verify which version is current before editing or auditing. Back every added datum, mechanistic claim, or revision with an explicit source pointer (author/year, section/table/figure/page, or file path/line); if primary verification is impossible, report the gap and omit unsupported claims.
